## ✨ Ce que présente le site

- **Cartes hors ligne** et sentiers guidés du parc.
- **SOS géolocalisé** pour la sécurité des randonneurs.
- **Quiz nature** pour découvrir la faune et la flore.
- **Annuaire de l'économie locale solidaire** : guides, artisans, hébergements.
- Un projet d'**écotourisme adapté aux changements climatiques**.

## 🧱 Réalisation

Site statique en HTML, CSS et JavaScript natifs, sans dépendance, optimisé pour le mobile et déployé sur Vercel.
